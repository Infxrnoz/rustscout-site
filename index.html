Setup

Running in two minutes

Install

Run the installer. If Windows shows "Windows protected your PC", click More info → Run anyway.

Link Steam

Open RustScout, click Link Steam and sign in. This connects it to Rust+.

Pair a server

In Rust, press Esc → Rust+ → Pair with server. It shows up in RustScout on its own.

Optional: add your own free API keys

Some extras use free keys that you get yourself and paste into Settings → Integrations. They stay on your PC, and nobody else's key is shared with you.

Steam Web API key: lists every Rust server in Browse and shows hours, friends and bans on Threats cards. Get it at steamcommunity.com/dev/apikey (any domain name works, like localhost).

RustMaps API key: adds resource heatmaps to the map. Sign in at rustmaps.com → Dashboard → API.

FAQ

Questions

Does it touch the game?

No. RustScout talks to Rust+, the same service the official Rust+ phone app uses, and draws its overlay in its own separate window. It doesn't read or change Rust's memory or files. Colour profiles change your display settings, like the NVIDIA Control Panel does.

Can I get banned?

RustScout doesn't read or change the game, but some servers ban overlays, crosshairs or colour changes in their own rules. You use it at your own risk, and we're not responsible for bans. See the terms.

Is it allowed on every server?

Rust+ works on any server that has it turned on. Some community servers don't allow crosshair overlays or gamma changes, so check the rules of the server you play on.

Why does it say "not answering Rust+"?

That server's Rust+ is down or its Rust+ port is blocked. It's on the server's side, and RustScout reconnects by itself once it's back. Telling the server admins usually gets it fixed.

Does the overlay work in fullscreen?

Use Borderless or Windowed mode in Rust's settings. Exclusive fullscreen draws over everything, including overlays.

How many PCs can I use Pro on?

One at a time. Each key activates on one PC. Got a new PC? Click Remove key in the app on the old one, then activate it on the new one.

I lost my licence key

Open a ticket in our Discord with the email you paid with and we'll send it again.

Where are shops, heli, cargo and other events?

On 6 August 2026 Facepunch removed shops (vending machines) and map events (patrol heli, cargo ship, Chinook, locked crates, explosions, the travelling vendor, oil rigs and airdrops) from Rust+. No companion app can see them anymore, so RustScout doesn't have shop search, sulfur tracking, event timers, event alerts or the chat commands for them. If Facepunch brings that data back, those features come back too.

Windows says "Windows protected your PC"

That's SmartScreen. It shows for apps that aren't code-signed yet, which RustScout isn't. Click More info, then Run anyway. The installer comes straight from our GitHub releases.

Mac or Linux?

Windows only for now.
